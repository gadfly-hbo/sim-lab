# SimLab v0.2 使用与验证说明

先打开 **index.html**，无需安装、构建或联网。文件包含全部 CSS、交互脚本与原 v0.1 内核，直接用桌面 Chrome / Safari 打开即可。本次也用真实 Chromium 验证了 `file://` 直接打开。若浏览器策略限制文件访问，可在此目录运行 `python3 -m http.server 4318 --bind 127.0.0.1` 后打开 `http://127.0.0.1:4318/`。

## 5 分钟评审路径

1. 首页点第一个起步样例，再点“生成实验草稿”。查看目标、边界与三方案，所有值均为合成默认值。
2. 点“查看并确认口径”，确认当前稿；点“运行三种方案”。比较三方案，切换队列 / 库存 / 现金，拖动 D0–D30 滑块，打开完整日账。
3. 在助手点“将日发货能力改为300”。先看差异与原内核计算影响；先试“放弃”，再重新提出并“采纳修改”。原结果保留并标记过期，导出暂停，旧确认失效。
4. 重新确认口径并运行。去“证据与口径”看单变量敏感性与守恒；去“检查与快照”固定一个快照，再修改参数，验证旧快照仍可下载。
5. 输入不支持的自由文本，观察明确提示。高级“运行状态演示”可体验已知失败、计算完成但回执丢失，以及查询同一回执；未知状态阻断盲目重跑。

也可直接编辑全部参数。未保存编辑会暂停运行与导出，并阻断切换导致的输入丢失；非法参数不执行。起步演示仅匹配三条完整样例；修改句式见助手“支持哪些输入”。没有宣称理解任意自由文本。

## 复跑

```sh
python3 build.py
node --check app.js
node tests/test_simlab.cjs index.html
```

浏览器脚本默认读取本机现有 metric-factory 的 Playwright 包，仅作为浏览器驱动，不在参考仓写文件。若另机已有 Playwright，通过 `PLAYWRIGHT_MODULE` 指向其模块路径，再运行脚本；通过 `SIMLAB_BASE_URL` 可指定已启动的本地静态预览。脚本不会安装依赖或调用模型。

## 明确限制与交付状态

Agent 是明确标记的脚本，没有真实 Pi / LLM、模型费用或真实业务数据。Pi 接法和完整工具合同是下一步工程方案；demo 未实现生产会话、事务、并发、权限、审计、跨进程预算或持久回执。

取消只验证了计算开始前的等待阶段；同步计算开始后无法在页面事件中物理中断。未知回执体验用本地保存的原计算结果查询恢复；它不证明分布式系统或断电恢复已实现。浏览器 localStorage 可被清除，最多固定 10 个快照，需下载留存。

第一版完整保留；当前与认可参考目录均只读；没有启动正式产品开发或部署。最终 Library 保存状态以随交付报告提供的实际结果为准，不能凭本说明推断上传成功。
